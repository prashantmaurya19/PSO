# Play Chess Online
-------------
**a Websocket + Kafka + SpringBoat + React Project to 
play chess over real time with other.**

### Docker Support
run below command to spin up server
```bash
git clone https://github.com/prashantmaurya19/PSO.git
cd ./PSO
docker build -t pso-img:latest .
docker compose up
```

**open the website at below url**
```
http://localhost:8080/
```
